# Spec Delta

## Purpose

为任务状态提供可复用的密度选择，使高信息密度队列可以减少徽标占用空间，同时保持状态文本、色调和可访问语义一致。

## ADDED Requirements

### Requirement: 状态徽标支持显式密度
状态徽标 SHALL 支持默认密度和可选紧凑密度；未指定紧凑密度时，现有消费者的尺寸和状态语义必须保持不变。

#### Scenario: 默认密度保持兼容
- **WHEN** 消费者只提供状态色调和内容
- **THEN** 系统使用默认密度渲染徽标，并保留原有文本和色调语义

#### Scenario: 选择紧凑密度
- **WHEN** 消费者显式请求紧凑密度
- **THEN** 系统减少徽标的间距、内边距和视觉占用，同时保留相同的状态文本与色调语义

### Requirement: 任务队列传递密度选择
任务队列 SHALL 提供可选的紧凑状态展示配置，并把该选择一致地应用到队列内每个任务的状态徽标。

#### Scenario: 队列启用紧凑状态
- **WHEN** 任务队列启用紧凑状态展示且包含多个任务
- **THEN** 每个任务的状态徽标均以紧凑密度渲染

#### Scenario: 队列未启用紧凑状态
- **WHEN** 任务队列未提供紧凑状态配置
- **THEN** 每个任务的状态徽标继续使用默认密度

### Requirement: 调度台任务队列使用紧凑状态
调度台 SHALL 在任务队列区域启用紧凑状态展示，不得影响 Agent 列表中的状态徽标密度。

#### Scenario: 调度台装配任务队列
- **WHEN** 调度台渲染任务队列和 Agent 列表
- **THEN** 任务队列使用紧凑状态徽标，而 Agent 列表保持默认状态徽标密度
